# Angel Developer

A creative, non-traditional web development agency portfolio built with vanilla HTML, CSS, and JavaScript.

## Features

- **Particle Animation Hero** — Interactive canvas-based particle network background
- **Glassmorphism & 3D Cards** — Modern glass-effect cards with 3D flip team profiles
- **Live Portfolio Showcase** — Paste any URL to preview website landing pages in real-time
- **Custom Cursor** — Animated cursor with hover effects
- **Tilt Effect** — Interactive 3D tilt on service cards
- **Scroll Reveal** — Smooth entrance animations on scroll
- **Infinite Tech Marquee** — Auto-scrolling technology stack banner
- **Testimonial Carousel** — Auto-rotating client testimonials
- **Floating Labels** — Material-style animated form labels
- **Fully Responsive** — Optimized for mobile, tablet, and desktop

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (Canvas API, Intersection Observer, CSS Transforms)
- Google Fonts (Space Grotesk, Inter)
- Font Awesome 6

## Color Scheme

- Primary: Blue (`#3b82f6`)
- Background: White (`#ffffff`) / Off-white (`#f8faff`)

## Getting Started

Simply open `index.html` in a browser or serve with any static file server.

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```
